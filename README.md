# Netflix-Content-Analysis-Dashboard.
# Project Overview
This project is an interactive Power BI dashboard built to analyze Netflix's content library. It provides insights into content growth, genre popularity, ratings, countries, and movie duration using interactive visualizations and KPI cards.
